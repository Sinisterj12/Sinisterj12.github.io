# Portfolio Preview Assets

Place public-safe screenshots and visual assets here only after they are sanitized.

Checklist before adding an image:

- No customer names, store numbers, addresses, emails, phone numbers, ticket IDs, order IDs, or private repo paths.
- No credentials, tokens, API keys, browser profile data, terminal prompts with private paths, or internal URLs.
- No private customer workflow details unless they are abstracted.
- Crop or blur anything that is not needed to explain the project.
- Prefer a short filename that names the public concept, for example `rdscore-search-preview.png`.
- Add image captions in the page text so the screenshot has context.

When no safe screenshot exists yet, use the abstract mock panels already built into the site.
